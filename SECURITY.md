# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub Private Vulnerability Reporting:

<https://github.com/JoaoVictorVM/gazua/security/advisories/new>

Do not open a public issue, and do not post attack payloads or exploit details in public issues or discussions.

Include in your report:

- The Gazua version (`gazua --version`), the Python version and the operating system.
- The smallest set of steps that reproduces the problem.
- The impact you observed.

Remove secrets, credentials and personal data from anything you send.

## Supported versions

Gazua is in pre-release. Only the latest published development version receives security fixes. This project does not commit to a response time.
